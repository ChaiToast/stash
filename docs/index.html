Install in 4 steps

The extension is not on the Chrome Web Store yet, so Chrome installs it in developer mode. Takes under a minute.

  1. Download the extension

    Grab stash-extension.zip from the latest GitHub Release, then unzip it.

  2. Open the Chrome extensions page

    Visit chrome://extensions and turn on Developer mode (top-right toggle).

  3. Load STASH

    Click Load unpacked and select the unzipped folder — the one containing manifest.json. The STASH icon appears in your toolbar.

  4. Start your first sync

    Open your Instagram Saved page in Chrome, click the STASH icon, and hit Start Sync. Posts upload and appear in your library, sorted by category.

💡 If Chrome asks you to re-enable the extension after an update, just repeat steps 2–3 with the new folder — your data lives in your dashboard, not the extension.

Before your first sync

The extension needs a STASH dashboard to sync into. Options:

🚀

Use the hosted dashboard

If the author shared a dashboard URL with you, connect the extension from Settings → Connect STASH Extension and start syncing.

🛠

Self-host (free tiers)

Clone the repo and run your own backend on Supabase's free tier + your Anthropic API key. Full setup guide is in the repo README.

# Self-host quick start
git clone https://github.com/chaitoast/stash.git
cd stash && npm install
npm run db:start && npm run db:reset
npm run dev --workspace=@stash/web
